# Use TraceML With Your Stack

Run your existing Hugging Face Trainer, PyTorch Lightning, or RF-DETR script
with `traceml run train.py`. TraceML instruments standard training
automatically. For custom PyTorch loops, MONAI, Ray, Accelerate, and DeepSpeed,
follow the setup in the matching guide below.
